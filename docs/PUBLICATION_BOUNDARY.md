# Safe public content boundary

The public repository is not the editorial source of truth. It represents **only** assets and metadata already approved for public publication. A successful build means the staging preview passed its local checks, not that all linked stories are factually correct or currently live.

Publication checks: published status only; canonical URLs on https://theraisinapost.com/; exact allowlisted fields; valid dates and sections; unique article links; escaped HTML; no private tokens or hidden editor notes. Do not store drafts, reader data, raw research notes, private Git history or personal credentials.

The existing Hostinger site remains live independently. No automated sync from private main or deployments to hostinger-live are configured in this starter.
